## Checks NOT performed, and what that means

- **No CLI-level automated test.** The CLI was driven by hand against a live
  database and behaved correctly, but nothing in the suite would catch a
  regression in `Program.fs`.
- **No corpus has been indexed from disk.** `Corpus` and `observedFrom` are
  implemented and unit-tested, but nothing reads `.sql` files yet, so
  `readers`/`writers` always return empty (correctly caveated). Observed
  relationships are therefore **unexercised on real data**.
- **No golden semantic snapshots.** Determinism is asserted by unit tests
  comparing two renders, not by a checked-in golden file.
- **No property/invariant tests.** Invariants are enforced by construction and
  covered by example tests.
- **Windows and macOS unverified.** linux-x64 only, so `NFR-005` is unproven.
- **One server major and one parser major.** Other pairings untested.
- **Overload resolution untested** — the fixture had a single signature, so
  `Q-027` and `HY-STRATA-2026-5E03` remain open.
