## What the increment added

Desired state grew from tables alone to tables, views, materialized views,
functions, procedures, indexes, triggers, constraints and a reference table's
rows. Each arrived with the same two questions answered: what can be compared
faithfully, and what must be disclosed as not compared.

## Defects found by the declare-then-diff round-trip

Ten separate rounds, every one of which passed the unit tests first:

| Round | Defect |
|---|---|
| 1 | False clean — a foreign key, a check and a default all differed and none was compared |
| 2 | Invented completeness category names; the fixture used the same invented names, so test and code agreed and both were wrong |
| 3 | Validation built on the catalog-blind resolver — `Resolved` means "resolved to a name", not "exists" |
| 4 | Type spelling: parser `int8` vs catalog `bigint`, 5 of 7 columns differing on spelling alone |
| 5 | `serial` is not a type — `bigserial` is `bigint` plus a sequence default |
| 6 | Routine identity: both `pg_get_function_*` renderings include parameter NAMES |
| 7 | A new table's indexes needed a second apply; reference data had the identical bug |
| 8 | Table creations not ordered by foreign key — such a project could not be applied at all |
| 9 | An unnamed constraint never converged; the parser fabricated the name `foreign_key` |
| 10 | Any constraint difference refused the whole apply |

The pattern is consistent enough to be worth stating plainly: **a unit test
written against the same mental model as the code confirms the model, not the
behaviour.** Every defect above needed a real server to surface. The round-trip
— declare, apply, re-plan, expect zero changes — is now the project's standard
check for anything touching the diff.

## Known limits, carried forward

- A trigger's `WHEN` clause cannot be compared: the file's clause is never
  deparsed and `pg_get_expr` refuses `tgqual` because OLD and NEW are two
  relations.
- plpgsql bodies are syntax-checked; control flow is not analysed.
- A schema rename is still a drop plus an add (`§86`).
- `EV-STRATA-2026-C9A4` and `D7B2` were timed on Debug builds; both amended.
